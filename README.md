# Assistants4Businesses

Static GitHub Pages landing page for a personal-assistant setup business.

## Preview locally

Because the Lottie JSON files are loaded with `fetch`, preview through a local web server:

```powershell
cd C:\Users\alish\workspace\Assistants4Businesses
python -m http.server 5500
```

Then open `http://localhost:5500`.

## Deploy to GitHub Pages

Commit the folder contents and enable GitHub Pages for the repository root or `/docs` depending on where you place these files.
